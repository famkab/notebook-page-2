DESIGN DECISIONS

Trade-offs I designed around

RISKQuality varies from run to runEvery answer in the test set was scored twice, and model settings stayed low-creativity, so drift showed up as a number before launch.
RISKFalse praiseAnchor answers at every band and synthetic near-misses in the test set cut false passes?FALSE PASSWhen the AI said an answer met the level but a human grader said it didn’t. The error that matters most for learners. from 58% to 27%.
RISKThe wrong languageAnything not in English scores 0, a hard rule in every prompt.
RISKLatencyFeedback is read mid-game, so speed was tracked alongside accuracy.
RISKCost and consistencyLearners give many of the same answers. Matching them first made scoring instant and cheaper, and the same answer always got the same score.
RISKWhat the learner readsTen words or fewer, in the first person, naming one fix, and strict on the score.
