The evaluation loop

  1. 01RubricFour CEFR?CEFRThe Common European Framework of Reference for Languages, the scale from A1 to C2 used to describe how well someone uses a language.-aligned bands.
  2. 02Anchor answers?ANCHOR ANSWERAn example answer for each rubric band, given to the scorer so it can see what each level looks like.An example answer at every band, for every activity.
